Animated Sidebar Menu — Mini Project**(Vanilla HTML and CSS)**

Project is live( https://himan-007.github.io/mini_project_static/) 

A responsive sidebar navigation menu built with pure HTML & CSS, showcasing advanced CSS techniques like smooth transitions, hover animations, and interactive UI effects — no JavaScript required
This project is a sleek, dark-themed sidebar menu overlaying a full-screen background image. It's designed as a practice project to demonstrate advanced CSS concepts — layout, transitions, animations, and hover interactivity — all achieved without a single line of JavaScript.

✨ Features
📱 Sidebar Navigation Menu — clean, icon-based menu with labeled links (Gallery, Shortcuts, Exhibits, Events, Store, Contact, Feedback)

🎯 Hover Effects — interactive hover states on menu items and social icons for better UX feedback

🎬 CSS Transitions & Animations — smooth, animated transitions applied across UI elements

🖼️ Full-Screen Background Image — immersive layout with an overlaying translucent sidebar

🔗 Social Media Icons — Facebook, Twitter, Instagram, and YouTube links in the footer

🎨 Modern UI Styling — minimalist dark theme with clean typography and spacing

💯 Pure CSS — no frameworks or JavaScript, built entirely with vanilla HTML & CSS

🛠️ Built With
HTML5 — semantic page structure
CSS3 — Flexbox/Grid layout, transitions, animations, and hover pseudo-classes

What I Learned
Structuring a fixed sidebar layout with an overlaying background
Creating smooth hover and transition effects using pure CSS
Working with CSS animations to enhance interactivity
Organizing and deploying a front-end project on GitHub
